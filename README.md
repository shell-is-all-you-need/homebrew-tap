# Homebrew tap

Install `shell-is-all-you-need` directly from this tap:

```sh
brew install shell-is-all-you-need/tap/shell-is-all-you-need
```

Alternatively, add the tap first and then use the short formula name:

```sh
brew tap shell-is-all-you-need/tap
brew install shell-is-all-you-need
```

The formula supports ARM64 and x86-64 on macOS and Linux.
